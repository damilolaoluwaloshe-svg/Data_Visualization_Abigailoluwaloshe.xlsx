 📌 Executive Summary
This project delivers an interactive "Revenue Dashboard" designed to analyze key commercial metrics across global markets. The dynamic visualization system aggregates "$13.33 Billion in Total Revenue" across "10,000 Orders", delivering detailed insights into sales channel distributions, order priority fulfillment, and item-type profitability.

By combining primary slicers (Geographic Region and Order Date ranges) with dynamic KPI scorecards, this tool empowers decision-makers to evaluate performance drivers and optimize revenue channels.


 🎯 Key Performance Indicators (KPIs)
* Total Revenue Generated: `$13,333,551,314.32`
* Total Orders Processed: `10,000 Orders`
* Average Revenue per Order: `$1,333,355.13`


 📊 Analytical Highlights & Visualizations

1. "Sales Channel Distribution (Pie Chart):"
   * Displays an exact '50% / 50% split' between 'Online' and 'Offline' sales channels, indicating balanced omnichannel adoption.

2. "Revenue by Order Priority (Column Chart):"
   * Urgent Orders: Highest total revenue contributor at "~$3.41 Billion".
   * Low & High Priority Orders: Following closely at "~$3.38 Billion" and "~$3.37 Billion" respectively.
   * Medium Priority Orders: Generated "~$3.17 Billion".

3. Revenue by Item Type (Horizontal Bar Chart):
   * Top Performing Categories:** Household goods (~$2.90B), Office Supplies (~$2.68B), and Cosmetics (~$1.79B).
   * Lower Volume Categories: Fruits (~$37.8M) and Beverages (~$185.5M).

4. Interactive Filtering System:
   * Country Slicer: Multiselect geographic filtering spanning global territories (e.g., Afghanistan, Australia, Belgium, Benin, etc.).
   * Timeline Slicer: Historical date range filtering covering transaction periods from 2017 to 2021.


#Technical Workflow & Data Pipeline
* Data Cleansing & Transformation: Handled missing attributes, standardized date fields, and structured product taxonomy in Power Query.
* DAX & Aggregations: Engineered key dynamic metrics for aggregate revenue, transaction counts, and average order values (AOV).
* UI/UX Design: Built an executive dark/gold dashboard theme featuring card callouts, custom chart color-coding, and cross-filtering controls.
